# CAMERA · 카메라 컬렉션

바디·렌즈·이종교배 컨버터·필름 재고를 관리하고, 바디/렌즈와 촬영 목적을 고르면 조합을 추천하는 대시보드.
`index.html` 한 파일로 동작하며 빌드가 필요 없습니다.

- 주소: <https://mystarbell.github.io/camera/>

## 무엇을 할 수 있나

- **요약** — 바디·렌즈·컨버터·필름 롤 수, 바디 종류 분포, 마운트별 렌즈, 수리·점검 중 장비, 확인이 필요한 항목, 필름 재고 부족·유효기간 임박 경고, **장전 중인 기체** 현황(장전된 바디만 카드로 + 바디·렌즈·필름을 함께 본 추천 상황 태그와 이유, 미삽입 기체는 하단에 작게 분리)
- **장비** — 바디 / 렌즈 / 이종교배 컨버터 / 필름 추가·수정·삭제
  - 바디: 필름 SLR · 레인지파인더 · TLR · 중형 · 컴팩트, **디지털(풀프레임·APS-C·M4/3)** 모두 지원
  - 필름 바디의 **장전 중인 필름**: 목록 카드에 `🎞️ 미삽입` / `🎞️ Kodak Portra 400 장전 중` 배지, `🎞️ 필름` 버튼으로 보유 필름·카탈로그에서 한 번에 장전하거나 `미삽입으로` 해제. 수정 화면에서는 스톡 선택/직접 입력 + ISO + 필름 메모(남은 컷 등)를 넣을 수 있고, ISO는 보유·카탈로그 목록에서 자동으로 찾아 채운다
  - 필터 칩: `전체` / `바디` / `장전 중` / `렌즈` / `컨버터` / `필름` — `장전 중`은 필름이 들어 있는 바디만 모아 보여 준다
  - 렌즈 공개 스펙(필터 구경·후드·최단 촬영 거리·렌즈 구성·무게) 표시
  - 컨버터: `렌즈 마운트 → 바디 마운트`와 배율(유리 없음 1× · 스피드부스터 0.71× · 텔레컨버터 1.4×). 최대 2단 경유까지 조합 계산
- **조합 추천** — **바디·렌즈를 비워 두고 목적과 상황만 골라도** 보유 장비 전체에서 바디+렌즈(+필름)를 골라 주고, 바디나 렌즈를 먼저 고르면 그 안에서 비교
  - 촬영 목적(스냅·인물·풍경·여행·실내) + **상황·조건 칩**: 동행(상관없음·혼자·아이랑 같이·데이트) · 장소(상관없음·도시 산책·자연·외곽) · 무게(상관없음·가볍게 주머니에·화질·감성 우선)
  - 직결 조합과 컨버터 경유(이종교배) 조합을 함께 점수순으로 비교
  - 35mm 환산 초점거리와 화각(°), 최대 조리개, 무게(추정), 컨버터 경유 단수, AF/MF, 적합도(목적 화각·상황 적합 분해) 표시
  - 카드마다 **왜 이 조합인지**(AF·화각·무게·동행·장소)와 감점 이유를 한두 줄로 표시
  - **현재 장전된 필름**을 결과 카드에 함께 표시(`🎞️ 현재 장전: Kodak Portra 160` / `미삽입 — 원하는 필름을 바로 장전할 수 있어요`)
  - 수리·점검 중 기체는 기본 추천에서 빼고 아래에 따로 안내(직접 고르면 경고 배지와 함께 낮은 점수로 표시)
  - 같은 기종(베이비 롤라이 3대 등)은 한 대만 남겨 목록을 채우지 않음
  - 목적에 맞는 필름 스톡 추천 + 그 스톡의 **보유 롤 수·유효기간**까지 연결
- **필름** — 재고(스톡·ISO·포맷·롤·유효기간) 표, 롤 수 ± 버튼, 스톡 카탈로그
- **데이터** — 장비 목록 JSON 내보내기/가져오기, 개인 기록 JSON 내보내기/가져오기, 초기값 복원

## 조합 계산 방식

- 마운트가 같으면 직결, 다르면 컨버터 목록에서 경로를 찾아 연결(최대 2단)
- 35mm 환산 = 초점거리 × 컨버터 배율 × 포맷 크롭계수
  - 35mm 1.00 / 120 6×6 0.55 / 120 6×4.5 0.62 / 120 6×7 0.50 / 127 4×4 0.77 / 풀프레임 1.00 / APS-C 1.50 / M4/3 2.00
- 목적별 목표 화각(35mm 환산): 인물 70–135 · 풍경 20–35 · 여행 28–50 · 실내 35–55 · 스냅 35–70
- 조리개가 밝을수록 가점, 컨버터 경유는 단수만큼 감점, 보유 필름이 있는 스톡은 가점
- 상황·조건을 고르면 **적합도 = 목적 화각 50% + 상황 적합 50%**로 다시 매깁니다
  - 아이랑 같이: AF(+)/자동 노출(+)/밝은 렌즈(+) · 수동 초점(강한 감점) · 85mm 이상·900g 이상(−)
  - 데이트: 35–60mm·f/2.8 이하·중형 판형(+) · 85mm 초과·24mm 이하·900g 이상(−)
  - 혼자: TLR·중형(+), 수동으로 천천히(+) · 120mm 이상 망원(−)
  - 도시 산책: 28–50mm(+), 85mm 초과·28mm 미만(−), AF(+)
  - 자연·외곽: 35mm 이하 광각·120mm 이상 망원(+), 55–120mm(−)
  - 가볍게 주머니에: 포켓 컴팩트(+40), 그 외 기체는 큰 감점, 700g 이상 추가 감점
  - 화질·감성 우선: 120/127 판형(+), f/2 이하 밝은 단렌즈(+), 브라이트스크린·Sonnar(+)
- 무게는 공개 스펙 기준 추정값이며, 수정 화면의 렌즈 무게를 넣으면 그 값을 씁니다

## 장전된 기체의 추천 상황

바디(자동초점·크기·판형) + 렌즈(초점거리·최대조리개) + 장전 필름(ISO·컬러/흑백·성격)을 함께 점수화해, 지금 들고 나가기 좋은 상황 태그 2개와 한 줄 이유를 붙입니다. 필름을 바꾸면 태그도 바로 다시 계산됩니다.

- `아이랑 외출` — AF·자동노출·밝은 조리개·ISO 400 이상 가점, 수동 초점·85mm 이상·중형은 감점
- `데이트 · 인물` — 35–60mm·f/2.8 이하·중형 판형·Portra 계열 가점, 초망원·흑백·28mm 미만 감점
- `맑은 날 / 흐린 날 도시 스냅` — 28–55mm·AF·주머니 크기 가점, 날씨 표현은 장전 필름 ISO(400 이상 = 흐린 날)로 결정
- `맑은 날 인물·감성` / `맑은 날 정사각 인물` — 40–85mm·f/2.8 이하·중형 판형·Portra 계열 가점, 127 4×4는 ‘정사각’
- `느긋한 혼자 산책` — 중형·수동·주머니 크기·400 이하 ISO 가점
- `여행·풍경` — 35mm 이하 광각, `실내·저조도` — ISO 800 이상·f/2 이하
- 렌즈를 고정하지 않은 교환식 바디는 `렌즈 교환식`으로 표시하고 바디·필름만으로 계산(물린 렌즈에 따라 달라짐)

## 개인정보 (시리얼·구입가·개인 메모)

- 이 페이지는 **공개 저장소**에서 서빙되므로, 저장소에 올라가는 초기 데이터에는 시리얼번호·구입가·개인 메모를 넣지 않았습니다.
- 장비 수정 화면의 **개인 기록** 칸(시리얼번호·구입가·구입일·개인 메모)은 브라우저 `localStorage`의 별도 키(`camera-dash-private-v1`)에만 저장되고 어디로도 전송되지 않습니다.
- **장비 목록 JSON**에는 개인 기록이 포함되지 않습니다. 개인 기록은 `데이터` 탭의 `🔒 개인 기록 내보내기`로 따로 백업하세요. 이 파일은 공개 저장소에 올리면 안 됩니다.
- 장전 중인 필름(스톡·ISO·메모)은 공개 정보로 다룹니다. 남에게 보이면 안 되는 내용은 `필름 메모`가 아니라 `개인 메모` 칸에 적으세요.
- 브라우저 데이터를 지우거나 기기를 바꾸면 함께 사라지니, 가끔 백업해 두는 편이 좋습니다.
