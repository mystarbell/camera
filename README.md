# CAMERA · 카메라 컬렉션

바디·렌즈·이종교배 컨버터·필름 재고를 관리하고, 바디/렌즈와 촬영 목적을 고르면 조합을 추천하는 대시보드.
`index.html` 한 파일로 동작하며 빌드가 필요 없습니다.

- 주소: <https://mystarbell.github.io/camera/>

## 무엇을 할 수 있나

- **요약** — 바디·렌즈·컨버터·필름 롤 수, 바디 종류 분포, 마운트별 렌즈, 수리·점검 중 장비, 확인이 필요한 항목, 필름 재고 부족·유효기간 임박 경고, **장전 중인 필름** 현황(대수·바디별 배지)
- **장비** — 바디 / 렌즈 / 이종교배 컨버터 / 필름 추가·수정·삭제
  - 바디: 필름 SLR · 레인지파인더 · TLR · 중형 · 컴팩트, **디지털(풀프레임·APS-C·M4/3)** 모두 지원
  - 필름 바디의 **장전 중인 필름**: 목록 카드에 `🎞️ 미삽입` / `🎞️ Kodak Portra 400 장전 중` 배지, `🎞️ 필름` 버튼으로 보유 필름·카탈로그에서 한 번에 장전하거나 `미삽입으로` 해제. 수정 화면에서는 스톡 선택/직접 입력 + ISO + 필름 메모(남은 컷 등)를 넣을 수 있고, ISO는 보유·카탈로그 목록에서 자동으로 찾아 채운다
  - 렌즈 공개 스펙(필터 구경·후드·최단 촬영 거리·렌즈 구성·무게) 표시
  - 컨버터: `렌즈 마운트 → 바디 마운트`와 배율(유리 없음 1× · 스피드부스터 0.71× · 텔레컨버터 1.4×). 최대 2단 경유까지 조합 계산
- **조합 추천** — 바디를 먼저 고르거나 렌즈를 먼저 고르고, 목적(인물·풍경·여행·실내·스냅)을 고르면
  - 직결 조합과 컨버터 경유(이종교배) 조합을 함께 점수순으로 비교
  - 35mm 환산 초점거리와 화각(°), 최대 조리개, 컨버터 경유 단수, 적합도 표시
  - 목적에 맞는 필름 스톡 추천 + 그 스톡의 **보유 롤 수·유효기간**까지 연결
- **필름** — 재고(스톡·ISO·포맷·롤·유효기간) 표, 롤 수 ± 버튼, 스톡 카탈로그
- **데이터** — 장비 목록 JSON 내보내기/가져오기, 개인 기록 JSON 내보내기/가져오기, 초기값 복원

## 조합 계산 방식

- 마운트가 같으면 직결, 다르면 컨버터 목록에서 경로를 찾아 연결(최대 2단)
- 35mm 환산 = 초점거리 × 컨버터 배율 × 포맷 크롭계수
  - 35mm 1.00 / 120 6×6 0.55 / 120 6×4.5 0.62 / 120 6×7 0.50 / 127 4×4 0.77 / 풀프레임 1.00 / APS-C 1.50 / M4/3 2.00
- 목적별 목표 화각(35mm 환산): 인물 70–135 · 풍경 20–35 · 여행 28–50 · 실내 35–55 · 스냅 35–70
- 조리개가 밝을수록 가점, 컨버터 경유는 단수만큼 감점, 보유 필름이 있는 스톡은 가점

## 개인정보 (시리얼·구입가·개인 메모)

- 이 페이지는 **공개 저장소**에서 서빙되므로, 저장소에 올라가는 초기 데이터에는 시리얼번호·구입가·개인 메모를 넣지 않았습니다.
- 장비 수정 화면의 **개인 기록** 칸(시리얼번호·구입가·구입일·개인 메모)은 브라우저 `localStorage`의 별도 키(`camera-dash-private-v1`)에만 저장되고 어디로도 전송되지 않습니다.
- **장비 목록 JSON**에는 개인 기록이 포함되지 않습니다. 개인 기록은 `데이터` 탭의 `🔒 개인 기록 내보내기`로 따로 백업하세요. 이 파일은 공개 저장소에 올리면 안 됩니다.
- 장전 중인 필름(스톡·ISO·메모)은 공개 정보로 다룹니다. 남에게 보이면 안 되는 내용은 `필름 메모`가 아니라 `개인 메모` 칸에 적으세요.
- 브라우저 데이터를 지우거나 기기를 바꾸면 함께 사라지니, 가끔 백업해 두는 편이 좋습니다.

## 아직 확인이 필요한 데이터

- Olympus 바디 모델·마운트·종류
- Rolleiflex 계열 모델명(베이비 4×4 / 35 계열)과 고정 렌즈 화각
- 보유 컨버터(이종교배) 목록과 배율(유리 있음/없음)
- 필름 스톡별 재고 롤 수와 유효기간
- 디지털 바디 보유 여부와 마운트
